# NOVA AI

NOVA AI is an independent, modular AI assistant platform.

## Vision

Build a general-purpose AI system with modular capabilities for:

- Conversational AI
- Persistent conversation memory
- Document intelligence and RAG
- Web research
- Tool execution
- Multiple LLM providers
- Experimental machine learning models

## Architecture

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- AI: Provider-based LLM architecture
- Knowledge: Embeddings + FAISS
- Memory: Persistent conversation storage

## Project Status

Under active development.
